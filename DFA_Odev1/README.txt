ODEV 1 - DFA TABANLI SOZCUKSEL ANALIZCI

Dosyalar:
lexer.py  : Python ile yazilmis sozcuksel analizci
ornek.java: Ornek Java kodu

Calistirma:
1. VS Code ile klasoru acin.
2. Terminalde python lexer.py yazin.
3. Java kodunu yazin. Bos satir ile bitirin.
4. Lexeme ve token tablosu ekrana yazilir.

Not: Bu odevde Java dilinin tum kurallari degil, odevde belirtilen temel token turleri desteklenmistir.
